### Fixed

- `sudo-ask-grant-setup.sh --verify` no longer fails on a real macOS machine (the first live install of #305 rolled itself back): the ticket check splits sudo's `Matching Defaults` line on commas outside quotes, so `env_keep+="COLORFGBG COLORTERM"` and similar quoted values no longer make `timestamp_timeout` "unreadable" (a quoted token that itself mentions `timestamp_timeout` still is); and the `revoke` / `revoke extra` checks ran `sudo -n -l CMD`, which only asks whether CMD is allowed at all (always true for an admin with a password), so they now run the commands and read sudo's own refusal. `grant`, `status` and `exec` get the same treatment: a refusal must be sudo's "a password is required" (C locale), not the helper's own exit code. New `--behaviour-checks` mode for tests. (#306)
