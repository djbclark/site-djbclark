### Fixed

- `sudo-ask-grant-setup.sh` ticket check: it splits the `Defaults>`/`Defaults!` entries sudo prints on one line (any `Defaults>` entry used to roll the install back with a misleading message), fails closed on numbers outside sudo's grammar, quoted values mentioning `timestamp_timeout`, and a missing, renamed or duplicated Runas section, and `--ticket-checks` runs the two `--verify` checks so a fake `sudo` tests them by behaviour. (#305)
- `sudo-ask` window helper, setuid bypasses closed: `chmod -x,u+s F`, `-w,+s` and `-x+s` are modes, and a cluster with a mode letter in it (`-Rx 4755 F`, `-fx u+s F`, `-vvx 4755 F`) ends BSD getopt at the letter so the next word is the mode (an option cluster that cannot be classified prompts); `install -pm 4755`, `-Sm4755` and `-pm4755` are read from the getopt cluster; every `tar`/`bsdtar`/`gtar`/`gnutar` extraction as root prompts whatever its flags, and so do `pax -r`, `cpio -i`/`-p`, `ditto -x`/`-k`, `unzip` without `-l/-t/-v/-p/-Z`, and `mtree -U`/`-u`. (#305)
- `sudo-ask` window helper, nested link swaps closed: a program or script typed inside a wrapper, `sh -c`, `find -exec` or `xargs` prompts when its path goes through a link the invoking user can repoint (or contains `..`); `/opt/homebrew/{bin,sbin}` are no longer on the helper's `PATH`; the README no longer claims that `exec` runs the realpath for nested programs. (#305)
- `sudo-ask` window audit sweep: it now covers `/private/etc`, `/private/var/db` and each volume under `/Volumes`, and the README lists exactly what is and is not swept. (#305)
- `sudo-ask --status --audit` (a NOPASSWD line, no window needed) is rate limited: one sweep a minute, one at a time, at most 120 s in total, and `--revoke` sweeps only when a grant file existed. (#305)
- Tests: a setgid-only source copy is refused, a stat error in `changed_since_grant` counts as changed, and the `tomllib` registry test skips on Python before 3.11. (#305)
- `sudo-ask` helper, follow-ups: a safe (root-owned) link is followed and its target walked for links the user can repoint; `status --audit` refuses an epoch outside 0..now+1 day before spending its slot (a 31-digit epoch was a traceback after the slot); `--revoke` with the grant file gone says when the log shows a grant that was never revoked. `sudo-ask-grant-setup.sh` usage and header list `--ticket-checks`. (#305)
