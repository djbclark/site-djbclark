# Generated area for `stayturgid`

This directory is owned by **`site-sync`**. Content is re-rendered from the
product checkout on each sync and recorded in `.lockfile.yml`.

Site inventory source: `inventory/hosts.yml`.

## Rules

- Do **not** hand-edit files under `generated/stayturgid/`.
- Hand edits are detected via the lockfile hash: `site-sync` exits 2 and lists
  the drifted paths unless you pass `--force-generated` (generated area only).
- Everything **outside** `generated/stayturgid/` is user-owned and is never
  touched by `site-sync`.
- Product upgrades: pull the product, then run `just site-sync` (or
  `mode=dry-run` first).
